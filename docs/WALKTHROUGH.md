# Reviewer walkthrough

1. **Overview:** Pulse combines news, recommendations, music and social posts in one personalized workspace. Show the responsive three-column layout and featured story.
2. **Personalization:** Open Customize, change topics and compact mode. Explain that preferences persist in the browser.
3. **Search:** Search for a visible headline, then a phrase with no matches. Reset filters.
4. **Save:** Bookmark a story; visit Favorites and open it.
5. **Reorder:** Drag using a card grip, demonstrate the lift/tilt motion, then refresh. Show keyboard move controls and Reset order.
6. **Appearance:** Switch between light and dark. Switch English/Hindi and reload.
7. **Profile:** Create a demo account at `/login`; edit name and bio. Be explicit that authentication is mocked and no password is stored.
8. **Live:** Apply a new-items notification. Explain that the SSE transport is real and its demonstration content is simulated.
9. **Engineering:** Show test results and README. Provider calls run on the server; failures have safe fallbacks; stale search responses cannot overwrite newer results.

Suggested length: 90–120 seconds. End on the dashboard in dark mode.
